# User guide

## Starting

```bash
pokecode
```

## Creating a project

```bash
pokecode new my-app
```

Projects are stored under `~/.pokecode/projects`.

## Running commands

```bash
cd ~/.pokecode/projects/my-app
pokecode run python3 main.py
```

## Interactive shell

Inside `pokecode`, use:

- `help` — show help
- `version` — print version
- `new <name>` — create project
- `run <cmd>` — run command
- `exit` — quit
